# # Gerenciador de produtos[terminal]
Projeto realizado em grupos na sala de aula.
## Objetivo
Compreender como funciona o trabalho em grupo em uma equipe de deselvolvedores, analistas e testers.
## Componentes
### Lógica de Programação
Estamos desenvolvendo em grupos um algoritmo utilizado python 3.1x.
### Redes
Fazemos o "deploy" do código em uma máquina virtual-ubuntu server.
### Processo de Desenvolvimento de software
Registramos requisitos funcionais e não funcionais, realizamos testes e aprendemos sobre o básico de CI/CP
